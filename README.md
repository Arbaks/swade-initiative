# SWADE Initiative Tracker

Клиентский трекер инициативы для Savage Worlds Adventure Edition.

## Запуск

На Windows после установки Node.js LTS можно просто запустить `START.bat`.

Или вручную:

```bash
npm install
npm run dev -- --host 127.0.0.1
```

## Проверка

```bash
npm test
npm run build
```

## GitHub Pages

Vite настроен с `base: './'`, поэтому содержимое `dist/` можно публиковать как статический сайт.

## Что уже есть в MVP

- настоящая колода из 54 уникальных карт;
- раздача инициативы и сортировка по SWADE;
- Быстрый, Медлительный, Холодные Нервы / Улучшенные Холодные Нервы;
- ручной выбор карты для Холодных Нервов;
- отдельная «Сдать карту» с немедленным сбросом;
- Дикие Карты и статисты, массовое добавление статистов;
- быстрое добавление: Enter создаёт статиста, окно остаётся открытым;
- кнопки «Выбыл» и «Удалить» прямо на карточке;
- быстрое добавление/снятие состояний через `+` на карточке;
- активный участник и кнопка «Следующий ход» в порядке инициативы;
- В шоке, Уязвим, Отвлечён + пользовательские состояния;
- ранения, усталость, выбытие;
- история карт и журнал событий;
- localStorage, экспорт/импорт JSON.


### Безопасное удаление
Участника нельзя удалить напрямую из активного боя. Сначала нажмите `Выбыл`: карточка уйдёт в конец стола и получит верхнюю строку `Вернуть / Удалить`.
